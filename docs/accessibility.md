# Accessibility

- Preserve semantic HTML and heading hierarchy in every UI change.
- Keep interactive elements keyboard accessible and give them clear focus states.
- Use descriptive text for buttons, links, and image alt text.
- Keep color contrast and spacing readable across mobile and desktop layouts.
- Do not replace accessible native elements with generic containers unless there is a strong reason.

## UI Expectations
- Maintain the current scroll and navigation behavior without introducing confusing focus traps.
- Ensure section headings remain meaningful and consistent with the page outline.
